# Close Task Protocol

Cerrar solo después de PASS.

Evaluar:
- ¿cambió comportamiento? → docs/modules;
- ¿cambió arquitectura? → architecture / technical decisions;
- ¿cambió progreso? → status;
- ¿hubo fricción repetible? → retrospective/lessons;
- ¿hay mejora de harness? → improvements.

Mover la carpeta de `tasks/active/` a `tasks/archive/`.
