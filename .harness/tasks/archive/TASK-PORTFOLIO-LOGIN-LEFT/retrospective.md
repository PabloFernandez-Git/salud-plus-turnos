# Retrospectiva

La captura de referencia permitió corregir la geometría inferior: el radio inferior pertenece al panel azul, mientras que el superior pertenece al claro. Bases de color continuas y radios CSS simples resolvieron la separación sin `clip-path`. La inspección del navegador detectó además que las ondas debían inclinarse más y que el turquesa superior necesitaba mayor intensidad.

No se requieren cambios de harness ni de arquitectura.
