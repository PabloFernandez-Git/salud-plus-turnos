# Reviewer / Verifier

Responsabilidades:
- revisar independientemente contra el Brief;
- inspeccionar diff y código, no confiar solo en el Implementation Report;
- verificar criterios de aceptación;
- revisar tests, seguridad, autorización, DB/RLS cuando corresponda;
- ejecutar checks relevantes;
- emitir PASS o CHANGES_REQUESTED con evidencia concreta.

No modifica silenciosamente los criterios para poder aprobar.
