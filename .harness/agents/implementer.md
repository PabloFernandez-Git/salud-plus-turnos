# Implementer

Responsabilidades:
- leer Brief + Plan + contexto indicado;
- realizar el cambio mínimo necesario;
- respetar arquitectura, seguridad y naming;
- crear/actualizar tests relevantes;
- ejecutar verificaciones posibles;
- actualizar documentación afectada;
- escribir `implementation-report.md` con hechos, no narrativa extensa.

No cambia alcance, producto o arquitectura sin escalar la decisión.
