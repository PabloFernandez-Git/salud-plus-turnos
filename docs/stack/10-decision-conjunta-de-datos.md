# 10. Decisión conjunta de datos

La combinación aprobada es:

**PostgreSQL + Supabase**

El criterio será:

- PostgreSQL → base de datos relacional;
- Supabase → infraestructura administrada para PostgreSQL;
- proyecto → reglas de negocio y modelo de dominio.

La prioridad seguirá siendo aprender y utilizar correctamente conceptos de bases de datos relacionales, no esconderlos detrás de la plataforma.
