# 19. Vitest

## ¿Qué es?

Vitest es el runner de tests unitarios que utilizaremos para probar lógica de negocio y utilidades en TypeScript.

Será especialmente útil para reglas como:

- generación de slots;
- detección de solapamientos;
- transiciones de estado;
- cálculos de disponibilidad;
- funciones auxiliares.
