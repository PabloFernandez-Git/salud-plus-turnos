# 28. Scripts de calidad

El proyecto expondrá comandos estándar como:

```text
npm run lint
npm run format
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

y podrá incluir:

```text
npm run check
```

para agrupar los chequeos rápidos.

Estos comandos serán parte importante del harness del proyecto y permitirán que Codex y otros agentes verifiquen automáticamente sus cambios.
