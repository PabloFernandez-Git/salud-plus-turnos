# 4. Decisión conjunta

La combinación elegida es:

**Next.js + React + TypeScript**

La intención no es utilizar un stack complejo por sí mismo.

La intención es disponer de:

- React para construir la interfaz;
- Next.js para estructurar una aplicación full-stack;
- TypeScript para mantener contratos y modelos claros.

El principio general será:

> utilizar la solución más simple que resuelva correctamente el requisito actual.

Las siguientes tecnologías se incorporarán únicamente después de ser discutidas y comprendidas.
