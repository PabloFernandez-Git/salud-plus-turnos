# 20. React Testing Library

## ¿Qué es?

React Testing Library permite probar componentes desde la perspectiva del usuario.

La prioridad será comprobar comportamiento visible e interacción, no detalles internos de implementación.

Ejemplo:

```text
Usuario envía formulario inválido
→ aparece mensaje de error
```

y no:

```text
variable interna isOpen = true
```
