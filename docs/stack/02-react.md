# 2. React

## ¿Qué es?

React es la librería sobre la que construiremos la interfaz de usuario.

Seguiremos trabajando con conceptos conocidos como:

- componentes;
- props;
- estado;
- hooks;
- eventos;
- composición.

## ¿Por qué lo elegimos?

React forma parte de la experiencia profesional que queremos seguir profundizando y es la base sobre la que funciona Next.js.

Además, el producto necesita una interfaz altamente interactiva:

- agenda;
- formularios;
- filtros;
- dashboards;
- tablas;
- modales;
- estados de turnos.

React encaja naturalmente con este tipo de aplicación.
