# 1. Framework y lenguaje

## Decisión aprobada

**Next.js + React + TypeScript**

### Criterio de uso

- Next.js será el framework principal de la aplicación.
- React será la base de la interfaz.
- TypeScript será el lenguaje utilizado en todo el proyecto.
- Se utilizará Next.js como framework full-stack, evitando inicialmente características avanzadas de rendering, caching u optimización que no sean necesarias para el MVP.
- Se priorizará una arquitectura simple e incremental.

### Estado

**Aprobado**
