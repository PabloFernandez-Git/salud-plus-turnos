# 2. Estilos y sistema de componentes

## Decisión aprobada

**Tailwind CSS + shadcn/ui**

### Criterio de uso

- Tailwind CSS será el sistema principal de estilos.
- shadcn/ui se utilizará como base para componentes UI comunes.
- Solo se agregarán componentes de shadcn/ui cuando exista una necesidad concreta.
- El código de los componentes agregados formará parte del repositorio y podrá modificarse.
- shadcn/ui no define la identidad visual final del producto.
- El diseño final, composición, jerarquía visual y experiencia de usuario seguirán siendo responsabilidad del proyecto.
- Se evitará incorporar componentes o dependencias innecesarias.

### Estado

**Aprobado**
